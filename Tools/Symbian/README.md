# WebKit for Symbian

WebKit 2.52.6 for Nokia Symbian^3, Anna and Belle phones, with a native browser and an ARM11 JavaScript engine.

## Features

- Modern web pages and fast JavaScript.
- Native touch controls, text input, clipboard and file transfers.
- Accelerated graphics, WebGL 1, audio, video and Web Audio.
- HTTPS, bookmarks, history and website storage.

## Download

Get tagged builds from [Releases](https://github.com/yeatse/WebKit-Symbian/releases), or download **sis** from the latest successful [Symbian build](https://github.com/yeatse/WebKit-Symbian/actions/workflows/symbian.yml?query=branch%3A2.52.6-symbian).

Install `symbian-webkit-icu.sis` on C: first, then `browser.sis`. The optional `jsc.sis` package provides the JavaScript shell. See the [installation guide](../../ReadMe.md#download).
