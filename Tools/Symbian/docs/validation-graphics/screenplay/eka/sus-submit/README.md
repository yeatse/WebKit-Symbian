# SUS optional dirty-region correction

Confirmed source bug: `surface_update_session::submit` used the raw value of IPC slot 3 to decide whether a dirty-region descriptor was supplied. A normal three-argument `TIpcArgs` leaves that unused value undefined and its argument type unspecified. A nonzero unused value therefore entered `read_descriptor`, which rejected the unspecified type and returned `KErrArgument` before publication.

The actual native caller `/workspace/symbian-screenplay-private-probe-work/screenplay_probe.cpp` calls `SubmitUpdate(KAllScreens, iSurface, buffer)` without a dirty region. Its private client is byte-identical to the browser client, SHA256 `380904ada53b188fb8580cbfb1e60e20e101d03ffff5de672676d0815225824f`. Both match the pinned official packing: slot 0 is screen, slot 1 is `TPckgC<TSurfaceId>`, slot 2 is buffer, and slot 3 is set only for a nonempty region. The package is a read-only 8-bit pointer descriptor over exactly `sizeof(TSurfaceId)`. `KAllScreens` is `0x00ffffff` in the public `suerror.h`, matching the HLE constant. No client packing correction is required.

Pinned public kernel `0c3208650587ac0230aed8a74e9bddb5288023eb`, `e32cmn.h:6431–6437`, shows that the three-argument constructor assigns only slots 0–2 and their type flags; its unused-argument documentation explicitly says the received value is undefined. Pinned graphics `ff133bc50e6158bfb08cc093b0f0055321dcde99`, `surfaceupdateserver.cpp:512–522`, queries the region descriptor length rather than testing its raw argument word. Verified original public sources are preserved under `upstream/` and pinned in the helper report.

The external minimal patch changes only the optional-region gate to test slot 3's descriptor-type flag. An unspecified slot is ignored regardless of its unused word. Explicitly supplied descriptors still pass the existing 8-bit, size and rectangle-count checks. It does not change surface registration, owned buffer copying, Available completion, version negotiation or Finish.

External apply-check, exact replay and reverse-check passed. Shared source and the original frozen 19-path candidate were not edited by this reviewer.

`verify_submit_contract.py` passed against the exact extracted baseline and corrected `read_descriptor` and `submit` bodies, compiled with ordinary host stand-ins and bounded public IPC fixtures. The baseline reproduces `KErrArgument` for omitted-slot nonzero sentinels. The corrected body ignores all four omitted-slot sentinels without reading region data. Both variants retain valid 8-bit const/mutable descriptors and empty regions, while rejecting malformed rectangle lengths, 16-bit descriptors and oversized regions. This is source/host-contract evidence; it does not prove execution through the full emulator or a native update.

The supplied host37 public JSON records an outer-audit pass and a distinct native capability result of `UNAVAILABLE` with SubmitUpdate/Available `-6`. This review does not replace that result with a success. Root owns host38 production compilation and native rerun. Finish's known pending-rendering error is a separate issue and must retain truthful completion/error behavior. The initial v3 source review missed this omitted-argument contract; this follow-up preserves the original frozen evidence and records the correction separately.
